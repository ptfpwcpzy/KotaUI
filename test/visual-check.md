# Go 版 KotaUI 浏览器验证

全新 Go 二进制在本地预览端口正常加载嵌入式中文登录页。页面包含 KotaUI 标题、安装时账号密码提示、账号字段、密码字段和登录操作，浅色卡片布局可正常显示。
登录后概览页可显示 CPU、内存、磁盘、证书与版本信息，左侧导航可正常切换。入站页能显示三协议说明、新增入口和无入站空状态。
新增入站对话框正常打开。VLESS + REALITY 会显示目标、握手端口、私钥、公钥、short_id 和 SNI；切换到 Hysteria 2 后，字段正确替换为上下行速率、TLS server_name 与可选混淆密码。
在隔离预览中提交 Hysteria 2 入站后，Go 后端可保存记录并刷新列表；列表正确显示名称、协议、端口、UDP 网络、启用状态和删除操作。
