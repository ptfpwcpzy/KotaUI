# KotaUI

轻量级 **Go + sing-box** 管理面板，适用于 Alpine、Debian 和 Ubuntu VPS。

支持 VLESS + REALITY、Hysteria 2、Shadowsocks 2022、TUIC，以及客户端流量统计与订阅管理。

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/ptfpwcpzy/KotaUI/main/install.sh)
```

安装时按提示设置证书、面板端口、路径和管理员账号。安装完成后可输入 `kota` 打开管理菜单。
